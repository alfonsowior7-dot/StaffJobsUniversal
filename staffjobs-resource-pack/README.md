# StaffJobs Resource Pack

**Version:** 2.0.0-beta.1  
**Target:** Minecraft Java 1.20.1  
**Theme:** Black / Green

## Contents
- `pack.png`: StaffJobs black-and-green pack icon.
- `assets/staffjobs/lang/en_us.json`: English names and labels reserved for StaffJobs resource-pack integration.

## Installation
1. Download this folder as a ZIP, or use the packaged ZIP artifact when one is published.
2. Put the ZIP in `.minecraft/resourcepacks`.
3. Enable **StaffJobs UI - Black & Green** in Options → Resource Packs.

## Important
This resource pack is an optional companion to the StaffJobs Fabric UI mod. The current dashboard draws its panels and controls directly in the client mod; this pack currently supplies the visual identity and localization namespace. It does not independently add dashboard screens or custom UI textures.
